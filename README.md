# 日文歌詞羅馬拼音

在 Spotify 網頁版的日文歌詞下方顯示羅馬拼音,並與播放進度同步高亮。

```
夢ならばどれほどよかったでしょう
yume naraba dorehodo yokatta deshou
```

給聽得懂旋律、但讀不了假名與漢字的人。

---

## 功能特色

**四種顯示方式**
純羅馬拼音、原文加羅馬拼音、原文加平假名、關閉。平假名模式適合已能閱讀假名、僅受阻於漢字的使用者。播放列上提供切換鈕,不需開啟設定。

**同步高亮**
隨播放進度逐句高亮。歌曲具備逐字時間軸時,可精確到逐字掃描。

**時間校正**
音訊延遲與個人反應時間因人而異。提供 ±0.5 秒的調整鈕與滑桿,範圍 -0.5 至 2 秒,調整後立即生效。

**外觀調整**
可自訂羅馬拼音的顏色與字級(60%–120%),提供六組常用色與自訂色盤。

**手動斷字**
長音節詞彙轉換後容易連成一串(如 `sukitootta`)。可自行插入空格,設定會依歌詞行記住,再次播放時自動套用。

**自訂讀音**
形態素分析必然存在無法辨識的詞。未轉換的字會標示紅色波浪底線,點擊即可補上讀音;已轉換但讀音有誤的詞,雙擊後可選取範圍修正。讀音以詞為單位儲存,適用於所有歌曲。

**共用讀音字典**
修正後可提交至共用字典,經確認後併入,所有使用者於 12 小時內自動取得,無須更新版本。字典分為通用條目與單曲條目兩層。

**歌詞備援**
Spotify 未提供歌詞的曲目,會改由 [LRCLIB](https://lrclib.net) 取得,並以浮動面板顯示。面板可拖曳、縮放,字級隨面板寬度調整。

## 安裝

正在 Chrome 線上應用程式商店審查中,通過後於此處提供安裝連結。

<details>
<summary>自行打包安裝(需 Node.js)</summary>

```bash
git clone https://github.com/psgo555/romaji-lyrics-extension.git
cd romaji-lyrics-extension
npm install
npm run build
```

開啟 `chrome://extensions`,啟用開發人員模式,點選「載入未封裝項目」並選擇 `dist/`。

</details>

**系統需求**

- 電腦版 Chrome(或其他 Chromium 核心瀏覽器)
- Spotify 網頁版 `open.spotify.com`

安裝檔約 15 MB,其中多數為日文斷詞辭典。辭典隨擴充功能內建,轉換完全在本機執行。

## 使用方式

播放日文歌曲並開啟 Spotify 的歌詞檢視,羅馬拼音會顯示於每句下方。

| 操作 | 方式 |
|---|---|
| 切換顯示方式 | 播放列「歌詞」按鈕旁的切換鈕 |
| 為拼音插入空格 | 點擊定位游標,按空白鍵切換該處的空格 |
| 補上未轉換的字 | 點擊紅色波浪底線的字,填入讀音 |
| 修正錯誤的讀音 | 於該詞上雙擊,選取範圍後填入讀音 |
| 提交讀音 | 修正面板中的「分享給大家」 |

讀音欄位接受假名或羅馬拼音,輸入時會即時顯示轉換後的假名與整句預覽。

## 設定

點選瀏覽器工具列的擴充功能圖示。所有設定即時生效,不需重新整理頁面。

| 設定 | 範圍 | 預設 |
|---|---|---|
| 顯示方式 | 四種模式 | 純羅馬拼音 |
| 高亮提前量 | −0.5 至 2 秒,每級 0.05 秒 | 0 |
| 拼音顏色 | 六組常用色或自訂 | Spotify 綠 |
| 拼音字級 | 60%–120% | 80% |
| 自訂讀音 | 檢視、編輯、刪除 | — |

顯示方式與讀音等設定透過 Chrome 帳號同步;手動斷字與面板位置僅儲存於本機。

## 隱私權

- 不含追蹤、分析或廣告程式碼
- 日文轉換完全在本機執行,歌詞文字不會傳送至任何伺服器
- 僅在需要向 LRCLIB 查詢歌詞時,傳送歌名、歌手名與曲目長度
- 共用字典為單向下載,不會上傳任何資料
- 讀音提交需由使用者主動確認並送出

完整說明見[隱私權政策](PRIVACY.md)。

## 回報問題

轉換錯誤請透過擴充功能內的「分享給大家」提交,內容會自動帶入曲名與該句歌詞。

其他問題與建議請開立 [Issue](https://github.com/psgo555/romaji-lyrics-extension/issues)。
