# 日文歌詞羅馬拼音

Chrome 擴充功能:在 Spotify 網頁版的日文歌詞下方顯示羅馬拼音,讓不懂假名的人也能跟著唱。

```
夢ならばどれほどよかったでしょう
yume naraba dorehodo yokatta deshou
```

## 能做什麼

- **四種顯示方式** —— 只看拼音 / 原文加拼音 / 原文加平假名 / 關閉。
  平假名模式是給「看得懂假名、只卡在漢字」的人用的
- **跟著歌聲亮** —— 唱到哪亮到哪。有逐字時間軸的歌會逐字掃過去
- **快慢可以自己調** —— 覺得太早或太晚亮,按 ±0.5 秒的按鈕即時對準
- **拼音可以自己切** —— 長單字黏成一串很難讀(`sukitootta`),
  點一下就能插入空格,下次播到同一句自動套用
- **讀不出來的字可以自己補** —— 轉換引擎一定會有不認識的詞,
  點那個字就能當場填讀音,之後所有歌都適用
- **Spotify 沒歌詞時的備援** —— 冷門曲目沒歌詞時,會去 LRCLIB 查並開一個浮動面板

## 安裝

**目前正在 Chrome 線上應用程式商店審查中**,通過後這裡會放上安裝連結 ——
到時候按一下「加到 Chrome」就好,不需要任何開發工具。

<details>
<summary>等不及?自己打包安裝(需要 Node.js)</summary>

1. 下載本專案(綠色的 **Code** 按鈕 → **Download ZIP**),解壓縮
2. 安裝 [Node.js](https://nodejs.org/),然後在 `files/` 資料夾執行:
   ```bash
   npm install
   npm run build
   ```
3. 打開 `chrome://extensions`,開啟右上角的**開發人員模式**
4. 點「**載入未封裝項目**」,選擇產生出來的 **`dist`** 資料夾

</details>

> **安裝檔約 15MB**,其中大部分是日文斷詞用的辭典。
> 那份辭典必須內建 —— Spotify 的網頁安全性設定會擋掉臨時下載,
> 而且這樣轉換才能完全在你自己的電腦上完成,歌詞不必送出去。

## 怎麼用

播放日文歌 → 按 Spotify 的**歌詞**按鈕 → 拼音就會出現在每句下面。

| 想做的事 | 怎麼做 |
|---|---|
| 換顯示方式 | 播放列上「歌詞」按鈕旁邊那顆小按鈕,點一下換一種 |
| 調整快慢 | 點瀏覽器右上角的擴充功能圖示,用 ±0.5 秒的按鈕 |
| 幫拼音加空格 | 點一下把游標放到要斷開的位置,按**空白鍵** |
| 補上讀不出來的字 | 點那個**紅色波浪底線**的字,填讀音(打羅馬拼音就行) |
| 修正讀錯的字 | 在那個詞上**雙擊**,選出範圍後填正確讀音 |

## 隱私

**沒有任何追蹤、分析或廣告。** 日文轉換全部在你自己的電腦上完成。

唯一會離開電腦的是**歌名與歌手名**,而且只在需要去 LRCLIB 查歌詞時才送出。
詳見 [隱私權政策](PRIVACY.md)。

## 回報轉錯的字

轉換引擎一定會有讀錯或讀不出來的詞。在畫面上修好之後,可以按「**分享給大家**」
把它送出來 —— 確認沒問題就會加進大家共用的字典,**其他人不必再遇到同一個錯字**。

[到這裡看已經收到的回報](https://github.com/psgo555/romaji-lyrics-extension/issues)
